# 首頁 YouTube 影片清單

`src/data/youtube-videos.json` 是隨網站部署的本地影片備援清單，初始四支影片及發布日期於 2026-11-07 從基金會公開頻道與影片頁確認。

首頁透過單層 Next.js Data Cache 保存清單，每 24 小時到期後，由下一次頁面請求觸發背景更新，不是固定時間的排程。HTTP 錯誤（YouTube RSS 常間歇回 404）、逾時、空白或格式異常一律視為失敗：已有快取時繼續顯示上次成功的清單，不會被舊的本地清單覆蓋；冷啟動且抓取失敗時改用本地 JSON，影片區塊不會消失。失敗後同一執行個體 10 分鐘內不再重抓，避免 RSS 故障期間每位訪客都觸發請求。失敗不改寫本地檔案。

執行 `npm run sync:youtube` 可比對 RSS 並更新本地 JSON。內容沒變時不寫檔，抓取失敗時保留原檔。`npm run build` 也會先執行同步，讓新部署附帶可取得的最新清單。

部署後不直接寫入專案 JSON：Vercel 執行環境的專案檔案不可作為持久儲存。部署期間的新影片保存在 Data Cache；本地備援檔在下次同步或建置時更新。RSS 再失效時沿用 Data Cache 中的清單；只有新部署或快取遭清除且 RSS 同時失效時，才回到該部署隨附的本地清單。
